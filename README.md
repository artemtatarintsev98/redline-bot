# Redline Bot v2

Multi-asset paper-trading scanner with daily self-tuning. Virtual capital, real market prices.

## Що робить
- **Кожні ~5 хвилин** (`scan-every-5-min`): сканує ~20 активів — 12 криптомонет (Binance), золото, срібло, нафта, EUR/USD, GBP/USD, USD/JPY, S&P 500, Nasdaq (Yahoo). Керує відкритими позиціями (стоп, ціль, ліміт часу; перевірка також по живій ціні), ранжує нові сигнали по всіх активах і відкриває найкращі. Лонг і шорт.
- **Щодня о ~20:40 за Хорватією** (`learn-and-report-daily`): для кожної пари «актив + стратегія» підбирає параметри на старих 70% історії й перевіряє на нових 30%.
  - **active** — довела прибутковість на нових даних → ризик 1% на угоду
  - **explore** — найкращі кандидати без доказів → ризик 0,25%, щоб бот пробував нові ринки
  - **benched** — збиткова в реальних угодах (5+ угод за 14 днів у мінусі) → вимкнена

## Стратегії
`trend_pullback` (відкат у тренді), `breakout` (пробій діапазону), `mean_revert` (відскок RSI).

## Запобіжники
До 5 позицій одночасно, максимум 50% капіталу в одній, денний ліміт збитку 3%, повна зупинка при просадці 15%.

## Файли
